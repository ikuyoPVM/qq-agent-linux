QQ 机器人点歌功能（优化版）
================================


【这是什么】

给「QQ Agent」用的点歌功能。
群里 @机器人 说「点歌 歌名」或者「来首 XX」，机器人会搜歌，
然后发一张音乐卡片出来，群友点一下就能跳去播放。
网易云音乐、QQ 音乐两个平台都支持。

这是一份「技能」（skill），不是「插件」（plugin）。
QQ Agent 里这两类是分开的，存放位置也不一样：
技能放在 skills 文件夹，插件放在 plugins 文件夹。
这一份要放 skills，装好之后也是在控制台的「技能」里看，不在「插件」里。


【怎么装】

1. 先把压缩包解压出来，会看到这几样东西：
       skill.json
       index.js
       lib 文件夹（里面还有两个文件）
       安装说明.txt（就是本文）

2. 找到 QQ Agent 的安装目录 —— 进去后应该能看到 resources、locales 这些文件夹。
   再进到 resources\app\skills\

   找不到安装目录的话：右键 QQ Agent 的桌面快捷方式 → 属性 →
   点「打开文件所在位置」，就到了。

   注意是 skills 这个文件夹，别放到旁边的 plugins 里 —— 那是插件的位置，
   放错了不会被认出来。

3. 在 skills 文件夹里面，新建一个文件夹，名字取：music

4. 把第 1 步解压出来的东西全部放进这个 music 文件夹。
   放好之后应该长这样：
       ...\resources\app\skills\music\skill.json
       ...\resources\app\skills\music\index.js
       ...\resources\app\skills\music\lib\search.js
       ...\resources\app\skills\music\lib\store.js

5. 不用重启 QQ Agent。它一直盯着这个文件夹，等几秒钟就会自动认出来。
   打开 QQ Agent 控制台，进「技能」页，能看到「点歌」就是装好了。


【怎么用】

在群里 @机器人，说「点歌 歌名」或「来首 歌名」就行。

另外还会这些：
  · 查歌词 —— 让机器人念两句
  · 重发 —— 说「刚才那首」「上一首」
  · 换版本 —— 机器人会提示同名的其他版本，说「要另一个」即可


【能调的几个设置】

装好之后，在控制台的「技能」页点「点歌」，能改这几项：

  · 默认音乐平台 —— 默认是「自动」：先搜网易云，网易云没有原唱再换 QQ 音乐。
    也可以锁死某一个平台。
  · 候选取几条 —— 默认 5，搜到多条时机器人会告诉你还有别的版本。
  · 归档已发送的歌 —— 默认开。开着才能用「查歌词」和「重发」。
  · 音乐卡片格式 —— 默认「自动」，一般不用动。
    搞不懂就别改，改成 native 会让 QQ 音乐的歌发不出卡片。

这几项不改也能正常用。


【如果卡片发不出去】

群里显示这么一句：

      发送者版本过低，无法展示内容

先说结论：这不是装错了，也不是 QQ Agent 的问题。

原因是这样的 —— 音乐卡片要发出去，必须先经过一个第三方的「音乐卡片签名服务」
处理一下。那个服务不是腾讯官方的，可能因为网络不通、被限流、或者服务方自己
调整规则而失效。它一旦不通，卡片就发不出来，群里就会显示上面那句话。

麻烦的地方在于：这种失败从机器人这边看不出来，它的日志还照样显示「发送成功」，
只有群里能看出不对。

碰到了可以按这个顺序试：
  · 确认这台机器能正常上外网
  · 等一会儿再点一次（可能只是对方临时故障）
  · 都不行就去原出处反馈，让作者看看签名服务是不是变了


【另外两件要知道的事】

· 搜歌和查歌词，走的是网易云和 QQ 音乐的公开接口。
  这些接口都不是官方开放的，同一个人短时间内搜太多次，可能会被临时限流，
  表现是搜不到歌。歇一会儿就好。

· QQ Agent 以后如果升级，正常情况下这个 skills 文件夹会保留，功能不受影响。
  万一发现「点歌」不见了，把压缩包再解压一次、按上面的步骤放回去就行。
